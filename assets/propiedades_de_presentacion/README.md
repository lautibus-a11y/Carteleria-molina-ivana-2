# Carpeta de Propiedades de Presentación

Aquí puedes colocar las imágenes de las propiedades seleccionadas que deseas mostrar en la cartelera.

## Estructura recomendada:

```text
assets/propiedades_de_presentacion/
  ├── propiedad-1/
  │   ├── portada.jpg
  │   ├── 02.jpg
  │   └── 03.jpg
  └── propiedad-2/
      ├── portada.jpg
      └── 02.jpg
```

Una vez subidas las fotos, agrega los datos de cada propiedad en `data/propiedades.json` o `propiedades.js` con el atributo `"activa": true`.
